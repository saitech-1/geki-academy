# GEKI brand symbol

`geki-symbol-light.svg` preserves the original vector paths from page 15 of the owner-supplied Geki Academy Brand Guidelines final.pdf. It contains the approved red sun and white torii symbol for dark backgrounds.

The shared logo displays the symbol at 50px beside the existing GEKI ACADEMY web typography. Preserve the artwork proportions and colors. The source PDF is not published with the app.
